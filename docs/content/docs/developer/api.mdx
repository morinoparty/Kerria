Kerriaは、外部プラグインから経済機能を利用するための2つの方法を提供しています。

## ServiceManager経由のAPI

Kerriaは起動時に `KerriaAPI` をBukkitの `ServiceManager` に登録します。
他のプラグインから以下のようにアクセスできます。

```kotlin
val registration = server.servicesManager.getRegistration(KerriaAPI::class.java)
val kerriaAPI = registration?.provider ?: error("Kerria is not loaded")

// アカウント管理
val accountManager = kerriaAPI.getAccountManager()
val account = accountManager.getOrCreateAccount(playerUUID, "PlayerName")

// 残高取得
val balance = accountManager.getBalance(accountId, currencyId)

// 入金・出金
val economyManager = kerriaAPI.getEconomyManager()
economyManager.deposit(accountId, currencyId, BigDecimal("100.00"))
economyManager.withdraw(accountId, currencyId, BigDecimal("50.00"))

// 通貨管理
val currencyManager = kerriaAPI.getCurrencyManager()
val currencies = currencyManager.getAllCurrencies()

// 取引ログ
val logManager = kerriaAPI.getLogManager()
val history = logManager.getTransactionHistory(accountId, limit = 10)

// 銀行管理（ギルド・町の金庫など共有残高）
val bankManager = kerriaAPI.getBankManager()
bankManager.createBank("guild_bank", ownerUuid)
bankManager.deposit("guild_bank", currencyId, BigDecimal("1000.00"))

// 為替レート・通貨変換
val exchangeRateManager = kerriaAPI.getExchangeRateManager()
exchangeRateManager.setRate(fromCurrencyId, toCurrencyId, BigDecimal("0.0067"))
val rate = exchangeRateManager.getRate(fromCurrencyId, toCurrencyId)
exchangeRateManager.convert(accountId, fromCurrencyId, toCurrencyId, BigDecimal("1000"))
exchangeRateManager.deleteRate(fromCurrencyId, toCurrencyId)
```

:::note
すべてのAPIメソッドは `Either<KerriaError, T>` を返します。
エラーハンドリングには Arrow の `fold`、`getOrNull`、`onLeft` などを使用してください。
:::

## Vault Economy API

Kerriaは [Vault](https://github.com/MilkBowl/Vault) Economy APIを実装しています。
Vault経由でアクセスする場合、操作はすべてデフォルト通貨に対して行われます。

```java
Economy economy = server.getServicesManager()
    .getRegistration(Economy.class).getProvider();

double balance = economy.getBalance(player);
economy.depositPlayer(player, 100.0);
economy.withdrawPlayer(player, 50.0);
```

:::info
Vault経由の取引では、呼び出し元プラグインが自動的に検出され、取引ログに記録されます。
:::

### 銀行機能（Bank）

Kerria は Vault の Bank API に対応しています（`hasBankSupport()` は `true` を返します）。
ギルドや町の金庫のような、複数プレイヤーで共有する残高を扱えます。銀行残高はデフォルト通貨で管理されます。

```java
Economy economy = server.getServicesManager()
    .getRegistration(Economy.class).getProvider();

// 銀行の作成（第2引数は所有者のプレイヤー名）
economy.createBank("guild_bank", "Notch");

// 入金・出金・残高照会
economy.bankDeposit("guild_bank", 1000.0);
economy.bankWithdraw("guild_bank", 200.0);
double balance = economy.bankBalance("guild_bank").balance;

// 所有者・メンバー判定
boolean isOwner = economy.isBankOwner("guild_bank", "Notch").transactionSuccess();
```

銀行の残高操作はプレイヤーの残高と同じアトミックな経路を通り、取引ログにも記録されます。
より細かい制御（メンバーの追加・削除など）が必要な場合は、`KerriaAPI#getBankManager()` から取得できる
`BankManager` を利用してください。`BankManager` の各メソッドは `Either<KerriaError, T>` を返します。

## カスタムイベント

Kerria は経済操作に関して、実行前・実行後の 2 種類のイベントを発火します。用途に応じて使い分けてください。

| イベント | 発火タイミング | キャンセル | 主な用途 |
|---------|--------------|-----------|---------|
| `KerriaTransactionEvent` | DB 反映の**前** | 可能 | 取引の監視・拒否（veto） |
| `KerriaTransactionCompletedEvent` | DB コミットの**後** | 不可 | 確定した残高変更の観測 |

:::warning
残高が実際に変化したことを確実に知りたい場合は、必ず `KerriaTransactionCompletedEvent` を使用してください。
`KerriaTransactionEvent`（事前イベント）は、その後の DB トランザクションが失敗してロールバックされる可能性があるため、
残高が変化したことを保証しません。
:::

### 事前イベント（KerriaTransactionEvent）

経済操作が実行される前に発火します。キャンセル可能で、他のプラグインが取引を監視・制御できます。

```kotlin
@EventHandler
fun onTransaction(event: KerriaTransactionEvent) {
    // 取引の種類を確認
    when (event.type) {
        TransactionType.DEPOSIT -> { /* 入金 */ }
        TransactionType.WITHDRAW -> { /* 出金 */ }
        TransactionType.TRANSFER -> { /* 送金 */ }
        TransactionType.SET_BALANCE -> { /* 残高設定 */ }
        TransactionType.CONVERT -> { /* 通貨変換 */ }
    }

    // 必要に応じてキャンセル
    if (shouldBlock(event)) {
        event.isCancelled = true
    }
}
```

| プロパティ | 型 | 説明 |
|-----------|-----|------|
| `type` | `TransactionType` | 取引の種類（DEPOSIT / WITHDRAW / TRANSFER / SET_BALANCE / CONVERT） |
| `fromAccountId` | `UUID` | 送金元アカウントID |
| `toAccountId` | `UUID` | 送金先アカウントID |
| `currencyId` | `Int` | 通貨ID |
| `amount` | `BigDecimal` | 取引金額 |
| `callerPluginName` | `String?` | 操作を実行したプラグイン名 |
| `isCancelled` | `Boolean` | キャンセル可能 |

### 確定後イベント（KerriaTransactionCompletedEvent）

経済操作が DB にコミットされた後に発火します。キャンセルはできず、確定した残高変更を通知します。
DB トランザクションの外側で発火されるため、リスナーからコミット済みの変更をロールバックすることはできません。

```kotlin
@EventHandler
fun onTransactionCompleted(event: KerriaTransactionCompletedEvent) {
    // 確定した残高変更を観測する
    val amount = event.amount
    val newFromBalance = event.fromBalance // 送金元の確定後残高
    val newToBalance = event.toBalance     // 送金先の確定後残高

    // 例: スコアボードの更新や通知など
    updateScoreboard(event.toAccountId, newToBalance)
}
```

| プロパティ | 型 | 説明 |
|-----------|-----|------|
| `type` | `TransactionType` | 取引の種類 |
| `fromAccountId` | `UUID` | 送金元アカウントID |
| `toAccountId` | `UUID` | 送金先アカウントID |
| `currencyId` | `Int` | 通貨ID |
| `amount` | `BigDecimal` | 取引金額 |
| `callerPluginName` | `String?` | 操作を実行したプラグイン名 |
| `fromBalance` | `BigDecimal` | 送金元アカウントの確定後残高 |
| `toBalance` | `BigDecimal` | 送金先アカウントの確定後残高 |

:::note
入金・出金・残高設定では送金元と送金先が同一アカウントとなり、`fromBalance` と `toBalance` は同じ値になります。
これらのイベントは `party.morino.kerria.paper.event` パッケージに定義されています。
:::
