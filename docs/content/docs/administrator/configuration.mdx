---
title: 設定ファイル
description: Kerriaの設定ファイル (config.conf) の解説
---

Kerriaの設定は `plugins/Kerria/config.conf` に [HOCON](https://github.com/lightbend/config/blob/main/HOCON.md) 形式で記述します。
初回起動時に、コメント付きの既定ファイルが生成されます。キー名は kebab-case（例: `default-currency-id`）です。

通貨の名前・記号・複数形・フォーマットなどはデータベースで管理しており、設定ファイルには含まれません。
通貨の作成・編集は [`/kerria currency`](/docs/administrator/commands) コマンドで行います。

:::note
以前のバージョンの `config.yaml` は読み込まれません。必要な値を `config.conf` へ手動で移してください。
:::

## 設定項目

```hcl
# デバッグモード
debug = false

# 既定の言語ロケール（例: ja, en）
default-locale = "ja"

economy {
  # 新規プレイヤーの初期残高（デフォルト通貨）
  initial-balance = 0.0
  # デフォルト通貨のID（/kerria currency default <name> で変更できる）
  default-currency-id = 1
}

database {
  # データベースの種類（sqlite | postgresql）
  mode = "sqlite"
  host = "localhost"
  port = 5432
  database = "kerria"
  username = "user"
  password = "password"
}
```

設定ファイルに書かれていないキーには既定値が使われます。
また、HOCON の置換を使うと環境変数から値を読み込めます。

```hcl
database {
  # 環境変数 KERRIA_DB_PASSWORD があればその値を使う
  password = "password"
  password = ${?KERRIA_DB_PASSWORD}
}
```

## default-locale

プレイヤーへ送信するメッセージの既定の言語ロケールです（例: `ja`, `en`）。
プレイヤーのクライアント言語に対応する翻訳が無い場合や、コンソール宛のメッセージでこのロケールが使用されます。
メッセージの多言語対応については[メッセージ設定](/docs/administrator/messages)を参照してください。

## economy

### initial-balance

新規プレイヤーがサーバーに初めて参加した際に、デフォルト通貨で付与される初期残高です。
デフォルト値は `0.0` で、初期残高は付与されません。

例えば `1000.0` に設定すると、新規プレイヤーはアカウント作成時に自動で 1000 が付与されます。

### default-currency-id

デフォルト通貨のIDです。`/balance`・`/pay`・`/kerria top`・`/kerria give` などで通貨IDを省略したときや、Vault・PlaceholderAPI 連携、初期残高の付与で使用されます。
`/kerria currency default <name>` を実行すると、この値が書き換えられます。

プラグイン初回起動時、通貨が1つも無ければ次の通貨がID `1` で作成されます。

| 項目 | 値 |
|-----|----|
| 名前 | `JPY` |
| 記号 | `¥` |
| 複数形 | `円` |
| フォーマット | `%amount% %plural%` |
| 小数点以下の桁数 | `2` |

## 通貨の表示形式

通貨の表示形式は、`/kerria currency edit` で通貨ごとに変更します。
`format` には次のプレースホルダを使用できます。

| プレースホルダ | 置換される内容 |
|--------------|--------------|
| `%amount%` | 桁区切り済みの金額（例: `1,234.56`） |
| `%plural%` | 通貨の複数形 |
| `%symbol%` | 通貨記号 |
| `%name%` | 通貨名 |

`thousandsSeparator` と `decimalSeparator` を組み合わせることで、表示スタイルを地域ごとに変更できます。

| 設定例 | フォーマット | 表示結果 |
|-------|------------|---------|
| `symbol` が `$`, 区切り `,` / `.` | `%symbol%%amount%` | `$1,234.56` |
| `symbol` が `€`, 区切り `.` / `,` | `%amount%%symbol%` | `1.234,56€` |
| `symbol` が `¥`, `fractionalDigits` が `0` | `%symbol%%amount%` | `¥1,234` |

## database

データベースの接続設定です。`sqlite` と `postgresql` をサポートしています。
