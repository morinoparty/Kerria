---
title: メッセージ設定
description: プレイヤーへ送信されるメッセージのカスタマイズ (messages.yml)
---

💬 Kerria がプレイヤーへ送信するメッセージは、すべて `plugins/Kerria/messages.yml` に外部化されています。
このファイルを編集することで、文言・色・装飾を自由にカスタマイズできます。

## ファイル形式

`messages.yml` は「メッセージキー」と「テンプレート」のフラットな対応表です。
キーはドット区切りで、値は [MiniMessage](https://docs.advntr.dev/minimessage/format.html) 形式で記述します。

```yaml
balance.result: "<green>あなたの残高は<amount>です。"
pay.success: "<green><yellow><player></yellow> に <amount> を送金しました。"
common.player-not-found: "<red>プレイヤー <yellow><player></yellow> が見つかりません。"
```

初回起動時に、デフォルトのメッセージが自動的に書き出されます。

## プレースホルダ

テンプレート内の `<name>` 形式のトークンは、コマンド実行時に実際の値へ置換されます。
利用できるプレースホルダはメッセージごとに異なります。主なものは以下の通りです。

| プレースホルダ | 説明 |
|--------------|------|
| `<player>` | 対象プレイヤー名 |
| `<amount>` | フォーマット済みの金額 |
| `<name>` | 通貨名 |
| `<error>` | エラーの内容 |

置換される値は MiniMessage として再解釈されないようエスケープされます。
そのため、通貨名などに `<` が含まれていても、意図しない装飾やタグの注入は発生しません。

## 色や装飾

MiniMessage のタグ（`<red>`、`<gradient>`、`<click>` など）はテンプレート側にそのまま記述できます。
装飾を変更したい場合は、テンプレートの MiniMessage タグを編集してください。

## 再読み込み

`messages.yml` を編集した後は、サーバーを再起動するか、設定の再読み込みコマンドで反映できます。
不正な YAML を保存した場合は読み込みがスキップされ、直前の正常なメッセージが維持されます。
