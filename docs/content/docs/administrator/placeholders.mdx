Kerria は [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/) と連携し、プレイヤーの残高や通貨情報をプレースホルダーとして公開します。スコアボード・タブリスト・チャット装飾など、PlaceholderAPI を参照する各種プラグインから残高を表示できます。

## 🔧 準備

PlaceholderAPI は任意依存です。導入している場合のみ連携が有効になり、未導入でも Kerria は通常どおり動作します。

1. サーバーに PlaceholderAPI を導入します。
2. Kerria を有効化すると、起動時に `kerria` エクスパンションが自動で登録されます。

登録に成功すると、サーバーログに `Registered PlaceholderAPI expansion.` と出力されます。

## 利用できるプレースホルダー

| プレースホルダー | 説明 |
|-----------------|------|
| `%kerria_balance%` | デフォルト通貨の残高（通貨フォーマット適用） |
| `%kerria_balance_raw%` | デフォルト通貨の残高（数値のみ） |
| `%kerria_balance_<id>%` | 指定した通貨IDの残高（通貨フォーマット適用） |
| `%kerria_balance_raw_<id>%` | 指定した通貨IDの残高（数値のみ） |
| `%kerria_currency_default%` | デフォルト通貨の名前 |

`<id>` には通貨IDを指定します。例えば通貨ID `2` の残高をフォーマット付きで表示する場合は `%kerria_balance_2%` を使用します。通貨IDは `/kerria currency list` で確認できます。

フォーマット適用版はコマンド出力と同じ通貨フォーマット（桁区切り・記号・複数形）で表示されます。数値のみが必要な場合は `raw` 版を利用してください。

:::info[取得に失敗した場合]
アカウントが存在しない、または残高の取得に失敗した場合でも、プレースホルダーは例外を投げず `0`（フォーマット適用版は `0` をフォーマットした文字列）を返します。参照側プラグインの描画を妨げません。
:::
