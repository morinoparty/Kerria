🚀 このページでは、Kerria をサーバーに導入して動かすまでの手順を説明します。

## 動作環境

Kerria を利用するには、次の環境が必要です。

| 項目 | 要件 |
|------|------|
| サーバー | [Paper](https://papermc.io/) 26.1 以上 |
| Java | Java 25 以上 |

:::note
Velocity プロキシによるクロスサーバー対応は開発中です。現時点では Paper サーバーへの導入に対応しています。
:::

## 依存プラグイン

Kerria は単体で動作します。追加のプラグインは必須ではありません。

- **Vault**（任意）: Kerria は Vault の Economy プロバイダーを提供します。ショップや他の経済系プラグインと連携する場合は、サーバーに Vault を導入してください。導入されていれば、Kerria が自動的に経済プロバイダーとして登録されます。詳しくは[API 連携](/docs/developer/api)を参照してください。
- **PlaceholderAPI**（任意）: 残高などをプレースホルダーとして表示できます。詳しくは[プレースホルダー](/docs/administrator/placeholders)を参照してください。

## インストール手順

1. [リリースページ](https://github.com/morinoparty/Kerria/releases) から Kerria の jar ファイルをダウンロードします。
2. ダウンロードした jar を、サーバーの `plugins/` ディレクトリに配置します。
3. サーバーを起動（または再起動）します。

起動すると、`plugins/Kerria/` に設定ファイルが自動生成されます。

:::warning
Kerria は残高データを扱います。運用中の導入・アップデートの前には、必ずデータのバックアップを取得してください。
:::

:::note
Kerria は現在開発中のため、バージョンアップにより破壊的な仕様変更が発生する可能性があります。
:::

## 初回起動後

初回起動時に、次のファイルが生成されます。

- `plugins/Kerria/config.yaml` — 通貨・データベース・言語などの設定
- `plugins/Kerria/translation/` — メッセージのロケール別ファイル（`ja_JP.properties` など）

既定ではデータベースに SQLite が使用され、追加の設定なしで動作します。PostgreSQL を利用する場合や通貨をカスタマイズする場合は、[設定ファイル](/docs/administrator/configuration)を参照してください。

導入が完了したら、次のページも確認してください。

- [設定ファイル](/docs/administrator/configuration) — 通貨・初期残高・データベースの設定
- [パーミッション](/docs/administrator/permissions) — 各コマンドに必要な権限
- [コマンド](/docs/player/commands) — プレイヤー向けコマンドの一覧
